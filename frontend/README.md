# RetailSense AI — Frontend

Development frontend for RetailSense AI built with Vite + React + Tailwind.

Requirements
- Node 18+
- npm

Install & run

```bash
cd frontend
npm ci
npm run dev
```

Build

```bash
npm run build
npm run preview
```

Notes
- API proxy configured to `/api` which forwards to `http://127.0.0.1:8000` in `vite.config.js`.
